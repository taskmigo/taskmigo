title: Local development
description: Run Taskmigo applications directly on one workstation.
---

Use this page when you want a fast edit-run loop for individual applications. For the complete deployed stack with
PostgreSQL, Gateway API routing, bootstrap ordering, web, worker, and browser client in Kubernetes, use
[Local Kubernetes](/docs/v0/developer/local-kubernetes).

## Prerequisites

Install the tools needed by the applications you plan to run:

- Java 26 for the server applications;
- Docker Desktop or Docker Engine with Compose for PostgreSQL;
- Node.js 24 for repository formatting;
- Node.js `26.7.0` and pnpm `11.24.0` for the browser client;
- Node.js 26 for the documentation site.

Install the locked root and documentation dependencies before running their checks:

```bash
npm ci
cd docs
npm ci
```

## Start PostgreSQL

The local Compose file starts PostgreSQL with the same connection details used by the server defaults.

```bash
cd server
docker compose up -d
docker compose ps
```

The database is available at `localhost:5432` with database, user, and password all set to `taskmigo`.

`apps/bootstrap` is the only application allowed to run Flyway migrations. Web and worker keep Flyway disabled and expect
an already-compatible schema.

To use another PostgreSQL instance, set `TASKMIGO_DATABASE_URL`, `TASKMIGO_DATABASE_USERNAME`, and
`TASKMIGO_DATABASE_PASSWORD` before launching an application.

## Run bootstrap

Bootstrap is a one-shot Spring Boot application. Run it before web or worker whenever the database is new or migrations or
installation-state reconciliation have changed.

The following local configuration creates the reserved `system` user and the browser OAuth client used by the Next.js
application:

```bash
cd server
export TASKMIGO_BOOTSTRAP_USER_PASSWORD='local-password'
export TASKMIGO_AUTH_BROWSER_ENABLED=true
export TASKMIGO_AUTH_CLIENT_SECRET='local-browser-client-secret'
export TASKMIGO_CLIENT_URL=http://localhost:3000
./gradlew :apps:bootstrap:bootRun
```

Bootstrap exits after Flyway and reconciliation complete. A non-zero exit means the runtime applications must not be
started against that database.

## Run the web application

The web application serves the HTTP API and OAuth endpoints on port 8080. It does not run migrations or reconcile OAuth
clients.

For a single-instance local environment, allow the web application to create its signing key on disk:

```bash
cd server
export TASKMIGO_OAUTH_SIGNING_KEY_AUTO_CREATE=true
./gradlew :apps:web:bootRun
```

Open [the API reference](http://localhost:8080/api/docs) after startup. The OpenAPI document is available at
`/api/docs/openapi.json`.

Automatic signing-key creation is only for one local instance. See [OAuth clients](/docs/v0/developer/oauth-clients) for
the configuration and deployment rules.

## Run the worker

The worker is a separate Spring Boot application without an HTTP server. It uses the migrated PostgreSQL schema and keeps
Flyway disabled.

```bash
cd server
./gradlew :apps:worker:bootRun
```

## Run the browser client

Use the same browser OAuth client secret that was supplied to bootstrap.

```bash
cd client
corepack enable
pnpm install --frozen-lockfile
cp .env.example .env.local
```

Set these local values in `.env.local`:

```dotenv
TASKMIGO_CLIENT_URL=http://localhost:3000
TASKMIGO_AUTH_ISSUER=http://localhost:8080
TASKMIGO_AUTH_CLIENT_ID=taskmigo-client
TASKMIGO_AUTH_CLIENT_SECRET=local-browser-client-secret
TASKMIGO_AUTH_SESSION_SECRET=local-session-secret-0123456789abcdef
TASKMIGO_AUTH_ALLOW_INSECURE_REQUESTS=true
TASKMIGO_AUTH_COOKIE_SECURE=false
```

Then start Next.js:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000). Use username `system` and password `local-password` for the bootstrap
login account.

If you change the browser client registration settings, rerun `apps/bootstrap` before restarting the client so the
persisted OAuth registration and client runtime configuration stay aligned.

## Run the documentation site

The documentation site is independent of the Taskmigo runtime applications.

```bash
cd docs
npm run dev
```

The development server prints its local URL. It normally listens on [http://localhost:3000](http://localhost:3000), so use
a different port when the Taskmigo browser client is already running there.

## Stop and reset local services

Stop PostgreSQL while preserving its data:

```bash
cd server
docker compose down
```

To discard the local database and force bootstrap to apply migrations to an empty database again, remove the named volume:

```bash
cd server
docker compose down --volumes
```

## Verify changes

Run the checks affected by your change before opening or updating a pull request.

Repository formatting:

```bash
npm run format:check
```

Server:

```bash
cd server
./gradlew --no-daemon build
```

Client:

```bash
cd client
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

For documentation changes, run the full documentation sequence from `docs/`:

```bash
npm run lint:check
npm run format:check
npm run types:check
npm run build
```
