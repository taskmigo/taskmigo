description: Local setup and implementation contracts for Taskmigo.

Use [Local Kubernetes](/docs/v0/developer/local-kubernetes) when you need a complete Taskmigo deployment with PostgreSQL,
Gateway API routing, bootstrap, web, worker, and the browser client in Minikube.

Use [Local development](/docs/v0/developer/local-development) for a faster edit-run loop when running individual
applications directly on your workstation.

The current implementation contract is intentionally limited to Organizations, Users, Groups, Roles, Projects, and
Project Membership.

See [Resource model](/docs/v0/developer/resource-model) for entities, relational constraints, and authorization
resolution rules.

See [Authorization](/docs/v0/developer/authorization) for Statement policies, request resources, authorization
snapshots, and database-side object filtering.

See [API reference](/docs/v0/developer/api-reference) for the interactive HTTP API documentation, its OpenAPI document,
and local authentication instructions.
